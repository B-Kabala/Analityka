# Analityka

Prosta aplikacja Hello World w Streamlit.

## Uruchomienie lokalne

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Udostepnienie

Aplikacje mozna wdrozyc na Streamlit Community Cloud, wskazujac:

- repository: `B-Kabala/Analityka`
- branch: `main`
- main file path: `app.py`
